# FvgEA

Personal MQL5 Expert Advisor exploring fair value gap detection and modular trade execution logic.

## Engineering focus

- Fair value gap detection with reusable include modules
- Separation of signal analysis and order execution
- Lifecycle cleanup and deterministic handling of chart objects
- Small, focused codebase suitable for studying modular MQL5 design

This is an experimental trading system for research and engineering practice, not financial advice or a promise of trading performance.
